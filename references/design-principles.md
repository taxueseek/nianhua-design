# 第一性原理、MECE 矩阵与视觉闭环规范（v5.1）

## 背景脉络：两大细分风格与年画三重历史功能

本规范立足 1950s—1990s 中国美术出版物实景样本与中国近现代出版史考据，拆分为**两大细分风格**并共用一套平面现代主义（Graphic Modernism）底层纪律：

1. **细分风格一：`nianhua-suoyang`（年画缩样 · 传统至现代集大成体系）**
   - 历史上「年画缩样」是美术出版社面向新华书店发行的内部订货样本，汇集了当时中国封面设计的最高水准与最丰富面貌——既有传统民间年画的工笔开光、民间剪纸锯齿线刻、木刻套色、吉祥纹样与毛笔书法题签，又有极度前卫的色块切割、极简大留白、摄影拼贴与突破现代印刷体束缚的手绘非标变形美术字。
   - **年画三重历史功能规律**：年画曾经同时承担三个功能——**节庆装饰**（明快饱满的节日仪式感与高对比套色）、**民间信仰表达**（对称礼制、祥瑞图腾与护佑秩序）、**大众视觉传播**（街头与书店远距一眼识别的巨型年份、手绘招牌大字与清晰出版编号）。三者合一，使年画缩样天然具备民间图形生命力与现代海报级的传播张力。
2. **细分风格二：`pioneer-book-series`（80s 先锋译丛 · 现代主义装帧体系）**
   - 以 1980 年代文艺丛书、美学译丛与思想画册为母体，主动吸收包豪斯与俄国构成主义营养：大面积单一底色或留白、圆形/三角/实心条带强行切割版面、低饱和灰绿/赭石/绛红书卷套印，以及把书名当作建筑梁柱构造的手工几何书名字。
3. **三种同代同源风味变体（`--flavor`）**
   - 上述两大细分风格均可按语义适配搭配三种同代风味：`ikko-geometric`（几何东方构成）、`marber-grid`（三分线框丛书）、`riso-overprint`（双专色孔版叠印）。

所有结构化词库真源统一存放在 [blueprints.json](../assets/blueprints.json)。

## 一、第一性原理：剥离正文括号参考与外部噪声

1. **剥离提示词正文中的括号原标题与内部黑话**：生图模型只执行可画的视觉物理描述，无法理解括号元标签（如「东亚排版网格法则」「核心视觉隐喻」「主从分区」「#D8432C」）。一切维度名称、HEX 色号、断代功能标签与锁字坐标，一律剥离到正文之外的**设计参考与锁字简报**中供人或排版工具阅读。
2. **剥离物理保存瑕疵**：原库纸本上的折痕、磨白边、氧化斑与翻拍白桌面是保存损毁痕迹，不是审美本身。默认直出全新干净、满幅裁切的平面印刷设计稿。
3. **历史断代语法严格区分（非单换年份词）**：
   - `1950s-60s`：道林/棉纸微纤维感，铅印套色沉稳，米黄/朱红/豆沙绿，老宋体与端庄楷隶，禁用 90 年代拼音饰带。
   - `1970s`：高饱和胶版专色（红/绿/黄/黑硬朗撞击），粗壮重黑与反白描边字，四象限田字格与票券框线，禁用 80s 低饱和译丛色板与烫金。
   - `1980s`（最高权重）：百花齐放黄金期，同时容纳铜版纸/布纹纸/烫金工笔缩样与先锋译丛几何构成，全谱系非标手绘美术字开放。
   - `1990s`：光洁铜版纸胶印、暖调胶片拼贴与高对比孔雀绿/橘红撞色，斜切黑体与 `'90` 缩略年份，禁用传统花边边框。
4. **吸收相邻年代与工艺精髓**：吸收手绘完稿制版字体骨相（对抗现代电脑印刷体同质化）、木刻留墨线与剪纸锯齿月牙刀口、二方连续回纹窄边、阴文篆刻方印、全大写拼音饰带，以及三至四色「六成主底 / 三成主体与字 / 一成点缀」物理面积占比锁色法则。

## 二、MECE 正交矩阵与跨轴约束

| 维度 | 枚举值（互不重叠） | 核心控制点 |
|---|---|---|
| **1. 细分风格** (`style`) | `nianhua-suoyang` \| `pioneer-book-series` | 区分集大成缩样体系与 80s 先锋译丛装帧体系 |
| **2. 历史功能** (`historical_function`) | `festive-ornament` \| `folk-belief` \| `mass-visual` | 映射节庆装饰、民间信仰礼制、大众传播张力 |
| **3. 历史断代** (`decade`) | `1980s`（默认最高权重）\| `1970s` \| `1950s-60s` \| `1990s` | 联锁纸质油墨、兼容色板、字骨与禁止饰件 |
| **4. 载体品类** (`format`) | `cover` \| `calendar` \| `poster` \| `pattern-book` \| `book-series` | 由 `style` 约束兼容品类与默认画幅 |
| **5. 骨架与下沉字区** (`skeleton` + `layout_id`) | `block-cut` \| `window-frame` \| `grid-minimal` \| `bleed-poster` | 每条具体 `layout` 自带专属 `title_zone` / `year_zone` / `sub_zone` |
| **6. 汉字排布网格** (`cjk_grid`) | `axial-axis` \| `modular-grid` \| `asymmetric-tension` \| `radial-expansion` \| `bilateral-mirror` \| `vertical-cjk-cross` \| `tight-brick-justify` \| `contour-stagger` | 控制文字排向（横/竖/斜），并与字形方向硬性校验 |
| **7. 字图空间手法** (`tactic`) | `standard` \| `type-mask` \| `type-overlap` \| `stepped-stagger` \| `negative-space` \| `repeat-band` | 格子锁定版式自动避让斜向打架手法 |
| **8. 三种风味变体** (`flavor`) | `none` \| `ikko-geometric` \| `marber-grid` \| `riso-overprint` | 按当前细分风格自动转译语义，且禁配冲突媒介/色系 |
| **9. 隐喻、媒介与饰件** | `metaphor` × `medium` × `accent`（`double-hairline` / `seal-stamp` / `pinyin-band` / `traditional-border` / `foil-gold` / `damask-paper`） | 吸收传统工艺与出版细节，受年代与骨架互斥约束 |
| **10. 色系与手工字骨** | `palette`（严格 3–4 色面积占比）× `typo`（非标手绘字骨） | 正文只写纯中文色名与占比，HEX 移入参考简报 |

## 三、三种同代同源可选风味变体（两大细分风格均适用）

1. **`ikko-geometric`（几何东方构成风味）**：在年画缩样中将民俗或现代意象提炼为剪纸般利落的正圆/半圆/三角硬边撞击；在先锋译丛中强化包豪斯纯平几何构成，绝对零渐变（互斥：`retro-film`、`gongbi-watercolor`）。
2. **`marber-grid`（三分线框丛书风味）**：在年画缩样中传承票券细线分栏秩序；在先锋译丛中以 1px 极细黑线或白线焊死「顶栏书名 / 独立年份格 / 下方矩形画窗」（自动筛选兼容构图并屏蔽冗余双线边框）。
3. **`riso-overprint`（双专色孔版叠印风味）**：在年画缩样中呼应单双色木刻与胶印轻微套印错位；在先锋译丛中强化低饱和专色半透明叠加与粗纤维纸肌理（互斥：`multi-spot`、`retro-film`）。

## 四、看图复诊与针对性调整协议（Image-Grounded Critique）

当用户上传生成的初稿图（或待改版参考图）要求诊断优化时，**先观测、再定病灶、后给改图补丁与重抽配方**：

1. **客观观察（What I See）**：陈述真实画幅、是否超出 3–4 色、有无 3D 渐变、每个汉字/数字的笔画完整度、字图遮挡与物理瑕疵是否回流。
2. **定位首要病灶（Main Diagnosis，至多选 1–3 项）**：
   - 病灶 A：崩字 / 缺笔 / 年份缩水（或扁宽字强行竖排导致粘连）
   - 病灶 B：传统废料回流 / 满屏堆砌无关花边
   - 病灶 C：3D 光影 / 渐变 / 景深破防
   - 病灶 D：字压死主体焦点
   - 病灶 E：做旧 / 折痕 / 实体桌拍误入
3. **双轨交付调整方案（Target Refinement）**：
   - **轨道 1 · 原图局部改图指令**：遵循不变量保护原则，锁定完好区块不变，仅修改病变区块。
   - **轨道 2 · 重抽升级配方**：调整 `--style` / `--decade` / `--flavor` / `--cjk-grid` / `--accent` 重新运行 `compose_prompt.py` 生成洁净版提示词。
